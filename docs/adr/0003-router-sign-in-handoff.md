# Router Sign-in Handoff via short-lived deep link

Classroom API Key redeem must stay bound to a Google user, but the extension must not keep a long-lived Portal session. After browser Google OAuth (`/auth/google/login?client=extension`), the router issues a short-lived, single-use Sign-in Handoff and sends the student to `/auth/extension/complete`, which opens `vscode://` / `cursor://vans-coding.pegasi-classroom-install/handoff?token=…` and shows the same token as a paste-code fallback. The extension redeems with invite code + handoff only (`POST /extension/sessions/redeem`); the URI never carries the API key. Model templates come from `GET /extension/chat-language-models`. Portal web redeem and install scripts remain emergency fallbacks.
